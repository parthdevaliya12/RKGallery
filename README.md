# 🌸 RK Gallery

A modern, responsive image gallery dedicated to the divine beauty of Radha Krishna. Built using React and Tailwind CSS, this project showcases a smooth UI with theme toggling, image downloads, and a functional contact form powered by Web3Forms.

---

## ✨ Features

- 🎨 **Beautiful Gallery UI** – Display high-quality Radha Krishna images
- 🌗 **Dark/Light Theme Toggle** – Switch between themes seamlessly
- 📱 **Fully Responsive** – Optimized for mobile, tablet, and desktop
- ⬇️ **Download Images** – Users can download images easily
- ℹ️ **About Us Section** – Information about the gallery and purpose
- 📩 **Contact Form (Web3Forms)** – Simple and secure form handling
- 🦶 **Footer Section** – Clean footer with links and contact info

---

## 🛠️ Tech Stack

- **React.js**
- **Tailwind CSS**
- **Web3Forms API**
